📘 1. Descripción General del Sistema

JumpServer Kiosk Manager es una solución autónoma de orquestación de quioscos RDP web para JumpServer Community Edition (CE). Permite a los administradores de sistemas y redes acceder a las consolas de gestión web de dispositivos de infraestructura (servidores de monitoreo Zabbix, routers MikroTik, firewalls FortiGate, hipervisores Proxmox, switches, consolas iDRAC y cámaras IP) a través del portal de JumpServer Luna.

Cada activo registrado genera un puente seguro y aislado en pantalla completa mediante un navegador Chromium embebido, garantizando auditoría centralizada, grabación de sesiones en video y control de accesos RBAC sin requerir el módulo comercial Enterprise Web Terminal.

⚡

Arquitectura Bajo Demanda (Ephemeral)

Los contenedores no permanecen encendidos en segundo plano. Se inician de forma automática en 1-2 segundos cuando alguien se conecta y se apagan solos tras 120s de inactividad, logrando 0% CPU y 0 MB RAM en reposo.

🔒

Aislamiento Estricto 1:1

Cada equipo dispone de su propio contenedor y volumen Docker independiente. Las cookies, sesiones activas y credenciales nunca se mezclan entre dispositivos.

🛡️

Hardening de Navegación

Chromium opera con políticas corporativas gestionadas: herramientas de desarrollador (F12) desactivadas, descargas bloqueadas e imposibilidad de salir del modo quiosco.

🔑

Persistencia de Credenciales

El almacén de contraseñas integrado de Chromium permite que recuerdes inicios de sesión del dispositivo sin riesgo de perderlos al reiniciar el contenedor.

🚀 2. Guía Paso a Paso: Cómo Agregar un Nuevo Dispositivo Web

Sigue estos sencillos pasos para aprovisionar un nuevo equipo en menos de 30 segundos:

1

Abrir el Dashboard de Administración

Ingresa en tu navegador a la URL del panel de control de quioscos:

http://192.168.1.220:8080/

Las credenciales administrativas por defecto son admin / admin.

2

Hacer Clic en "+ New Device Kiosk"

En la esquina superior derecha del panel, pulsa el botón violeta + New Device Kiosk. Se abrirá la ventana emergente de aprovisionamiento.

3

Completar los Datos del Dispositivo

  • Device Name: Nombre identificatorio del activo (ej: ZABBIX-LOCAL, ROUTER-MIKROTIK, SW-CORE-01). Este mismo nombre aparecerá en JumpServer.
  • Device Type Profile: Selecciona la plantilla adecuada (Zabbix, Router, Switch, Proxmox, FortiGate, iDRAC o Genérico).
  • Protocol & IP: Protocolo (HTTP o HTTPS) y la dirección IP privada del dispositivo (ej: 192.168.1.110).
  • Port: Puerto web del equipo (por defecto 80 para HTTP o 443 para HTTPS).
  • Path or Custom URL (Opcional): Si el servicio requiere una ruta específica, puedes ingresarla aquí. Ejemplo: http://192.168.1.110/zabbix/ o /zabbix/.
4

Pulsar "Provision & Link JumpServer"

El sistema ejecutará de forma autónoma en pocos segundos:

  • Asignación de un puerto RDP exclusivo en el rango 33891 - 33920.
  • Creación del volumen persistente para almacenar sesiones del navegador.
  • Registro del activo en JumpServer con certificados permisivos (ignore_cert: true).
  • Creación de la cuenta de acceso y autorización con firma HMAC-SHA256.
  • Inicio del listener en el Dispatcher.
5

Conectar y Utilizar en JumpServer Luna

¡Listo! Puedes conectar de dos formas:

  • Conexión Directa desde el Dashboard: Haz clic en el botón verde 🚀 Conectar en la fila del dispositivo. Se abrirá la sesión de Luna de inmediato.
  • Desde JumpServer Luna: Accede a http://192.168.1.220/luna/, busca el dispositivo en la lista de activos y haz clic para conectar.
💡 Consejo Pro: La primera vez que inicies sesión en la web del dispositivo (ej. usuario Admin / clave zabbix), permite que Chromium guarde la contraseña. Gracias al volumen persistente dedicado, no tendrás que volver a escribirla en futuras sesiones.

❓ 4. Preguntas Frecuentes y Consejos Operativos

¿Por qué el estado del contenedor dice "💤 En Espera (0% RAM)"?

Es el comportamiento normal y deseado. Para no consumir la memoria RAM de tu servidor Proxmox, los contenedores solo se encienden mientras alguien los está usando. Cuando te desconectas, tras 120 segundos se detienen automáticamente para ahorrar memoria.

¿Qué hago si cambié la IP o ruta de un equipo?

No necesitas borrar el dispositivo y crearlo de nuevo. Simplemente haz clic en el botón ✏️ Editar, ingresa la nueva URL (ej: http://192.168.1.110/zabbix/) y presiona "Guardar Cambios". En tu próxima conexión, el quiosco abrirá la nueva ruta automáticamente.

¿Cuántos dispositivos puedo agregar simultáneamente?

El pool predeterminado asigna puertos desde el 33891 hasta el 33920 (30 quioscos). Si necesitas más puertos, se puede ampliar el rango fácilmente en el archivo .env del backend.
